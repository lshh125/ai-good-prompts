# Good AI Prompts

A collection of reusable AI prompts for life and work. Each prompt is stored in a plain-text `.txt` file with a short title and description.

## Prompts

- [paper-html-en.txt](paper-html-en.txt): Create an English HTML reading guide that explains a paper's argument, evidence, and limitations, with annotated passages and self-check questions.
- [manuscript-1st-round-html.txt](manuscript-1st-round-html.txt): Create an HTML companion for a first editorial pass, mapping experiment inputs and outputs, paragraph claims, and the overall argument. Local logic checks stay separate so readers can form their own judgment.

## Use

Copy a prompt into your AI assistant, fill in the bracketed placeholders, and attach or paste the requested source material. Both current prompts request a single HTML file that you can open in a browser.
